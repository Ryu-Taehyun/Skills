## code-checker

프로젝트를 스캔해 문제를 찾아 보고하고, 사용자가 승인하면 커밋·푸시까지 진행합니다.

**점검 항목**
- `.env` 등 파일 속 DB 접속 정보·키 같은 민감정보 위치 확인 (값은 노출하지 않음)
- 불필요한 함수와 중복 로직 검토 (테스트 결과 활용)
- 예외 처리와 비동기 처리의 올바름·일관성 확인

**결과물**
- 단계별 수정 필요 여부 표시
- 파일 구조와 주요 파일을 ASCII 로드맵으로 정리, 사용 모듈을 언어별로 분류
- 공개 시 다른 사용자의 만족도 예상 점수 (1~10)

**원칙**
- 사용자의 명시적 승인 없이 파일 수정, 커밋, 푸시를 하지 않습니다.
- 치명적인 오류가 발견되면 커밋·푸시 여부를 묻지 않습니다.

## 사용 방법

`code-checker/` 폴더를 Claude의 스킬 폴더에 넣고 프로젝트 점검을 요청하면 됩니다.
